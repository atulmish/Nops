# age test vectors

Copied unmodified from the age test vectors in [C2SP/CCTV](https://github.com/C2SP/CCTV/tree/main/age/testdata),
which allows reuse without attribution. Only vectors decrypted with an X25519 identity are included;
scrypt (passphrase) and post-quantum vectors are out of scope for Nops. Used by `AgeCctvTests`.
