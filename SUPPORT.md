# Getting help

- **Usage questions and ideas:** [GitHub Discussions](https://github.com/atulmish/Nops/discussions)
- **Bugs:** [open an issue](https://github.com/atulmish/Nops/issues/new/choose) with the Nops version, the file format and a minimal reproduction. Redact real secrets from anything you attach.
- **Documentation:** <https://atulmish.github.io/Nops/>
- **Security problems:** do not open a public issue. Use a [private advisory](https://github.com/atulmish/Nops/security/advisories/new), see [SECURITY.md](SECURITY.md).
